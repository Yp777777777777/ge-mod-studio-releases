# GE Mod Studio

Build car and map mods for **Gran Emozione** on your phone, test them in the game and publish them to [granemozione.online](https://granemozione.online/#mods).

## Download

**[Download GEModStudio.apk](https://github.com/Yp777777777777/ge-mod-studio-releases/raw/main/GEModStudio.apk)** (latest version, about 24 MB)

Version and release notes for every build are on the [Releases](https://github.com/Yp777777777777/ge-mod-studio-releases/releases) page.


## Install

1. Open the APK on your Android phone (Android 10 or newer).
2. If Android asks, allow installing apps from your browser or file manager.
3. Open **GE Mod Studio** and sign in with your Gran Emozione account to publish mods.

## What it does

- Every `data.ini` setting for cars and maps, with the official guide's help next to each field
- Power and torque curves, gears, aero, lights, wheels
- Map spawns, objects, lights and scripts
- Checks your mod against the game's rules before you install it
- Installs straight into the game's mod folder, or saves a zip
- Publishes to granemozione.online and shows when moderators approve it
- Opens community mods from the website as new projects

This repository only hosts the app downloads.
